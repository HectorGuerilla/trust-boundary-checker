# Sample Trust Boundary Section

- **Runs:** locally / browser / our cloud / your cloud
- **Reads:** files, repositories, tickets, logs, prompts, credentials, none
- **Sends externally:** exact data or "nothing by default"
- **Stores:** what, where, and for how long
- **Permissions requested:** exact scopes and why
- **Write actions:** none / after confirmation / automatic
- **Telemetry:** what events and how to disable
- **Failure modes:** false positives, false negatives, unsafe cases
- **Revoke/uninstall:** how to remove token, app access, local files
